# Beveiliging

Vond je een kwetsbaarheid, of een manier om vervalste inhoud te laten doorgaan voor PlanB72? Meld het vertrouwelijk via een [GitHub security advisory](https://github.com/montobleu/planb72/security/advisories/new) en niet als openbaar issue.

Vervalste noodinformatie onder onze naam is het grootste risico van dit project. Pakketten en startprogramma's worden daarom ondertekend (in opbouw).
